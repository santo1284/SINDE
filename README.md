# SINDE - Mini Red Social

Aplicación móvil de red social desarrollada en Kotlin para Android.

## Descripción
SINDE (Sindesparches) es una mini red social que permite a los usuarios interactuar, compartir contenido y conectarse. Proyecto desarrollado como aplicación Android nativa.

## Tecnologías
- Kotlin
- Android SDK
- Firebase (Authentication, Firestore, Storage, Functions)
- Jetpack (ViewModel, LiveData, etc.)

## Características
- Registro e inicio de sesión
- Publicaciones
- Interacción entre usuarios
- Almacenamiento en la nube con Firebase
